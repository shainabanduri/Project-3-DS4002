## Overview

This project trains convolutional neural networks to classify microscopic blood smear images as cancerous (acute lymphoblastic leukemia) or normal using the C-NMC 2019 dataset. We use transfer learning with ResNet50 and VGG16 backbones, fold-based cross-validation splits, and inverse-frequency class weighting to address the ~2:1 class imbalance. Hyperparameter tuning compares architectures and learning rates, with weighted F1 as the primary metric (target ≥ 0.90).

## Reproducing the Results

### Step 1 — Get the dataset

The dataset zip (`data/C-NMC 2019 (PKG).zip`) is included in this repo. If it is missing (GitHub rejects files over 100MB), download it here:

**[Download C-NMC 2019 (PKG).zip from Google Drive](https://drive.google.com/file/d/1s9NF82x-rwMXRdIqNhHkyFhouU_FRpF8/view?usp=sharing)**

**For local scripts (`01_eda.py`, `03_data_appendix.py`):**
Unzip `C-NMC 2019 (PKG).zip` into `data/` so that `data/C-NMC 2019 (PKG)/C-NMC_training_data/` exists. The scripts read directly from the extracted folder — they do not use the zip.

**For the Colab notebook (`02_train_evaluate.ipynb`):**
Upload `C-NMC 2019 (PKG).zip` to the root of your Google Drive. Cell 1 of the notebook mounts Drive and unzips it automatically inside Colab — you do not need to extract it locally first.

### Step 2 — Exploratory Data Analysis (local)

From the repo root:

```bash
pip install numpy pandas matplotlib Pillow
python scripts/01_eda.py
```

Three PNG plots will be saved to `output/`:
- `q1_class_distribution.png` — cancer vs. normal class balance
- `q2_fold_distribution.png` — image counts per fold
- `q3_brightness_by_class.png` — brightness distribution by class

### Step 3 — Training and Evaluation (Google Colab)

1. Upload `data/C-NMC 2019 (PKG).zip` to the root of your Google Drive
2. Open `scripts/02_train_evaluate.ipynb` in [Google Colab](https://colab.research.google.com/)
3. Set the runtime to **GPU** (Runtime → Change runtime type → T4 GPU)
4. Run all cells in order. The notebook will:
   - Mount Google Drive and unzip the dataset automatically (Cell 1)
   - Build fold-based train/val/test splits (Cell 5)
   - Train ResNet50 and VGG16 with two-phase fine-tuning (Cell 9)
   - Sweep learning rates on the winning architecture (Cell 10)
   - Evaluate the best model on the held-out test set (Cell 11)
   - Save all figures and `classification_report.txt` (Cell 12)
   - Download all output files to your local machine (Cell 13)
5. Move the downloaded files into `output/`

## Key Design Decisions

- **Fold-based splits**: fold_0 + fold_1 → train, fold_2 → validation (not random 80/20)
- **Class weighting**: inverse-frequency weights passed to `CrossEntropyLoss` to handle ~2:1 imbalance
- **Two-phase training**: Phase 1 warms up the classification head (backbone frozen, 3 epochs); Phase 2 fine-tunes the full network (ReduceLROnPlateau, patience=4)
- **Mixed precision**: `torch.amp.autocast` + `GradScaler` for faster GPU training
- **Primary metric**: weighted F1 (accounts for class imbalance); target ≥ 0.90
